# site_data 스키마 — 네이버웹툰_남성인기10_댓글반응분석

원본: Google Sheet `1piiExttOJm8lvChadOsinE9BWzA6Y-7Bv6Vs5C8L_Sg` (Sheets 커넥터로 읽기 전용 내보내기, 2026-10-27 KST).
모든 파일: UTF-8(BOM 없음), 쉼표 구분, 첫 행 헤더, 셀 안 줄바꿈은 큰따옴표로 감싼 RFC 4180 형식. 값은 시트에 **표시된 그대로**(FORMATTED_VALUE) 저장. 숫자 열에 천 단위 쉼표 없음 → `Number()`로 바로 변환 가능.
조인 키: `작품` (10개 작품명, 모든 탭 공통). `작품목록.titleId`는 네이버웹툰 작품 ID.

## 개인정보 확인
- 댓글 작성자 ID·닉네임 **열은 어느 탭에도 없음** (양식설명 '개인정보' 행: 수집·저장하지 않음).
- `댓글분석.댓글 원문` 본문 속 타인 ID 언급은 `w***`처럼 마스킹된 2건뿐 (참교육/범죄도시 매크로 고발 댓글). 마스킹 상태 그대로임.
- `작품목록.작가`는 작품 제작진(공개 크레딧, 예: "JP(글)·부겸(그림)")이며 댓글 작성자 정보가 아님.
- 수식 오인 방지용 U+200B(보이지 않는 문자)가 댓글 1건 앞에 붙어 있음 → 화면 표시 전 `.replace(/\u200B/g,'')` 권장.
