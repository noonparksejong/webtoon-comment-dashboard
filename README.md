# 네이버웹툰 댓글 반응 분석 대시보드

네이버웹툰 남성 인기 10작품의 댓글 반응을 시각화한 한국어 정적 사이트입니다. 남성 독자는 장르·발화 정황에 의한 추정이며 공식 성별 순위가 아닙니다.

## GitHub Pages 배포

1. 이 변경을 `main` 브랜치에 병합합니다.
2. 저장소의 **Settings > Pages**로 이동합니다.
3. **Build and deployment > Source**에서 **Deploy from a branch**를 선택합니다.
4. **Branch**에서 **main**, 폴더에서 **/ (root)**를 선택하고 **Save**를 누릅니다.
5. 배포가 끝나면 `https://noonparksejong.github.io/webtoon-comment-dashboard/`를 엽니다.

빌드·패키지 설치가 필요 없습니다. 루트의 `.nojekyll`은 Jekyll 처리를 생략합니다.

## 데이터 주소 변경

`assets/config.js`의 `window.DATA_SOURCES`에 6개 탭별 주소가 있습니다. 기본값은 `./data/<탭>.csv`입니다. CSV 원본은 수정하지 않고 읽기만 합니다.

구글 시트로 전환하려면 시트의 **파일 > 공유 > 웹에 게시**에서 각 탭을 **쉼표로 구분된 값(.csv)** 형식으로 게시한 뒤, 해당 탭의 값을 게시 CSV URL로 바꾸세요.

```js
'댓글분석': 'https://docs.google.com/spreadsheets/d/e/게시ID/pub?gid=탭ID&single=true&output=csv',
```

나머지 다섯 탭도 같은 방식으로 교체합니다. 원래 열 이름과 `작품` 연결 키를 유지하세요. 편집·공유 링크 대신 로그인 없이 읽을 수 있고 CORS를 허용하는 게시 CSV 주소가 필요합니다. 게시 범위에 개인정보가 없는지 확인하세요. 시트 게시 서버의 갱신 지연은 있을 수 있습니다.

사이트를 열거나 **새로 불러오기**를 누르면 모든 CSV를 `fetch`로 다시 읽습니다. 기존 쿼리를 유지하며 `t=타임스탬프`를 추가하고 `cache: 'no-store'`를 사용합니다. 데이터 불러온 시각은 한국 시간으로 표시합니다. 실패하거나 필수 열이 없으면 오류 안내와 재시도 버튼을 표시합니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행하고 `http://localhost:8000`을 여세요. `file://`로 직접 열면 CSV fetch가 제한될 수 있습니다.

```sh
python3 -m http.server 8000
```

브라우저 개발자 도구의 콘솔과 네트워크 탭에서 오류 및 CSV 6개의 응답을 확인할 수 있습니다. Chart.js 4.4.8과 PapaParse 5.5.3은 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 구성과 집계 기준

- `index.html`: 섹션·앵커 목차, 접근 가능한 차트 설명
- `assets/style.css`: 밝은 테마와 모바일 레이아웃
- `assets/app.js`: CSV 로딩·검증·집계·시각화
- `assets/config.js`: 탭별 데이터 URL
- `data/`: 제공된 CSV 6개와 `schema.md` (원본 유지)

작품별 공감과 반응 군집은 분석 표본의 공감 수 합계입니다. 감정 비율과 욕구 히트맵은 댓글 개수 기준이며 `-`는 ‘해당 없음’으로 포함합니다. 대표 회차 댓글 수는 답글 포함 전체 수치로, 400개의 분석 표본과 다릅니다. 별점은 별도 0~10 눈금으로 표시합니다. 판정은 앞 단어에 따라 확인·부분 확인·미확보로 묶되 세부 원문과 반례를 함께 제공합니다. 댓글 원문의 U+200B는 화면 표시 시 제거합니다. 작성자 ID·닉네임을 추가하거나 수집하지 않습니다.

조회수 비공개, 무료 회차 조회 범위 제한, 공감순 표본 편향, 독자 성별 미확인 등의 한계는 사이트 하단과 방법론 전체 보기에 표시합니다. 기획 시사점과 본질적 욕망은 해석·추정을 포함합니다.
